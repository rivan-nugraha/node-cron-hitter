## Node Cron For Birthday, Hutang, And Send Promo

# Instalation
1. Run "npm run setup"
2. Put Your IP And Endpoint On url-hutang.js and url-ulang-tahun.js
3. Run First Locally For Checking Is Running Or Not
4. Run It Using pm2 Then Check It On Browser On "You're IP:PORT/check-node-cron"

# NOTE
1. If you have run "npm run setup" dont run again it will be replace your data before
2. If you doesn't have the url-send-promo.js or gone just run "npm run setup-promo"
3. If you doesn't have the url-ulang-tahun.js or gone just run "npm run setup-ulang-tahun"
4. If you doesn't have the url-hutang.js or gone just run "npm run setup-hutang"
4. If you doesn't have the .env or gone just run "npm run setup-env"
